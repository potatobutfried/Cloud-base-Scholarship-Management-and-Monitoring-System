🎓 Firebase Simple Test (No Auth)

Scholarship Management System - Testing Without Authentication

⚠️ IMPORTANT: Update Firestore Rules First!

Before using this tool, you MUST update your Firestore security rules to allow writes without authentication.

📝 Required Firestore Security Rules

Go to Firebase Console → Firestore Database → Rules, and replace with:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Note: This rule allows anyone to read/write your database. Only use for development/testing!
